# Pulsar

Un jeu de rythme en cercle : les notes foncent vers une étoile depuis huit directions. Tourne le bouclier pour les attraper et frappe les anneaux roses. Les 200 morceaux de Rythme, ou ta propre musique.

Les 200 morceaux composés de Rythme, ou une musique de NeoMusic analysée par le jeu. Souris ou flèches pour tourner le bouclier, espace ou clic pour les anneaux. Plein écran pendant la partie, difficulté calculée en étoiles, note finale de S à D.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Pulsar → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
